# 项目问答补充指导

维护人员可在此目录建立 `<项目ID>.md`，例如项目9使用 `9.md`。
内容与上级 `analysis_questions.md` 共同交给模型，可补充工序提问方向、特征映射、方位及推荐依据。没有项目文件时使用通用指导与当前项目路线参考。

保存文件后，下一次进入第三步或刷新路线时，尚未开始回答的节点使用新生成内容。已开始回答的节点保留原问答定义，已保存答案和第四步审核规则不会被文件修改覆盖。需要整体重做时使用已有“重新回答全部”。

这些文件由项目维护人员编辑，不增加终端用户提示词维护入口。候选和推荐仍需通过系统约束校验；推荐缺少依据时保留人工回答，不填入虚构的零件实际参数。
