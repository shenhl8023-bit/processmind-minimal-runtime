## 源数据质量与待核对事项

1. **17 条量具记录的测量范围上下限反向。** 系统保留源值并标注异常，不擅自交换数值。这些记录的异常范围不能作为目标尺寸查询的有效依据；需要核对原 Excel 对应工作表、行号和单元格，确认后修正源数据。
2. **CP-636、CP-637 的 Ra 范围为 32 → 6.3，存在上下限异常。** 系统保留原值并提示核对，不将其自行改成 6.3～32，也不据此生成可达粗糙度结论。需要核对原表的列含义及数值方向。
3. **目录记录不等于完整工艺关联。** 存在设备、刀具或量具主数据，不能据此推断其与某条加工能力存在明确关系。只有稳定 ID 或历史直接记录支持的关系才可作关联结论；缺少关系时继续显示“仅有类别线索”或“样例未提供”。

源数据异常仍应由原表维护者核对，不能用模型经验替代。当前验证不等于完成全量原始 Excel 的语义校对，也不把主数据目录中的资源视为已验证的企业实机或具体规格适配关系。
