# 多样本工艺路线全集生成与冲突最小化算法解题思路

## 1. 问题背景

当前有多个典型零件样本，每个样本包含一条有顺序的工艺阶段、工序或工步序列。例如：

```text
样本1：A → A1 → B → C → D → E → F → G → H → I → J → K → L → M
样本2：A → B → B1 → C → D → D1 → E → F → G → H → I → J → K → L → M
```

所有样本中的节点可以合并成一个全集，但全集本身没有顺序。目标是从多条样本路线中恢复一条全局顺序，使其尽可能满足所有样本的先后关系。

该问题不是普通的数值排序，而是：

> **多序列偏序关系恢复、加权共识排序和工艺路线拓扑排序问题。**

如果所有样本的先后关系完全一致，可以使用普通拓扑排序得到合法全集路线；如果样本之间存在冲突，则需要求一条违反约束最少、总体一致性最高的全局路线。

## 2. 数学定义

设共有 `m` 条样本路线：

```text
S1 = [v1, v2, ...]
S2 = [u1, u2, ...]
...
Sm = [...]
```

所有节点的全集为：

```text
V = union(S1, S2, ..., Sm)
```

需要输出一个全局排列：

```text
P = [p1, p2, ..., pN]
```

其中 `N = |V|`，并尽量满足每个样本中的局部先后关系。

例如样本中出现：

```text
A → C → D → G
```

则全局结果必须尽量满足：

```text
A < C，C < D，D < G
```

样本中没有同时出现的两个节点，不应人为增加先后约束。

## 3. 与普通拓扑排序的区别

普通拓扑排序要求所有约束都必须满足。如果存在：

```text
B → C
C → B
```

则图中形成环，普通拓扑排序无法得到结果。

但样本数据中出现这种情况是正常的，因为不同零件可能采用不同的工艺顺序。因此本问题需要区分两类约束：

### 3.1 硬约束

来自工艺知识或工程规则，不能违反。例如：

```text
粗加工 → 半精加工
半精加工 → 精加工
热处理 → 精加工
```

### 3.2 软约束

来自样本统计的顺序偏好。例如：

```text
B → C 在 8 个样本中出现
C → B 在 2 个样本中出现
```

此时倾向于保留 `B → C`，但不一定要求绝对满足。

## 4. 数据预处理

算法效果首先取决于节点标识是否稳定。建议在算法前完成以下处理。

### 4.1 工序和工步标准化

将同义名称统一，例如：

```text
精车外圆、外圆精车 → turn_outer_finish
粗车外圆、外圆粗车 → turn_outer_rough
```

### 4.2 重复工序区分

如果同名工序在不同阶段重复出现，不能只使用名称作为节点。例如：

```text
车削
```

可能需要拆分为：

```text
turn_outer_rough
turn_outer_semi_finish
turn_outer_finish
```

更稳定的节点 ID 建议由以下信息组成：

```text
典型零件类别 + 特征对象 + 工艺阶段 + 工序/工步编码
```

### 4.3 样本合法性检查

每条样本内部应检查：

- 是否存在重复节点；
- 是否存在空节点；
- 是否存在无法识别的别名；
- 是否有工序和工步混用；
- 是否需要将工序节点展开为工步节点。

## 5. 关系统计方法

### 5.1 相邻关系图

对于样本：

```text
A → C → D → G
```

建立相邻边：

```text
A → C
C → D
D → G
```

相邻关系适合：

- 构建初始工艺路线图；
- 检测局部顺序冲突；
- 输出“某个样本的哪两个相邻工步被违反”。

### 5.2 全对关系统计

为了进行共识排序，需要统计同一条样本中所有节点对的先后关系。

例如：

```text
A → C → D
```

产生：

```text
A < C
A < D
C < D
```

定义：

```text
w(i, j) = 在样本中 i 位于 j 之前的次数
```

例如：

```text
w(B, C) = 8
w(C, B) = 2
```

说明样本总体更支持 `B → C`。

## 6. 推荐算法架构

建议采用两级算法：

```text
快速基线：多数关系图 + 冲突检测 + 带优先级拓扑排序
正式求解：加权 Kemeny 排序 / 加权最小反馈弧集 + CP-SAT
```

两级算法的关系如下：

- 基线算法用于快速预览、调试和生成初始解；
- CP-SAT 用于生成理论上更优的冲突最少全局路线；
- 两者结果可以对比，用于发现数据质量或权重设置问题。

## 7. 基线算法：多数关系图加权拓扑排序

### 7.1 建立多数关系

对于每一对节点 `i` 和 `j`：

```text
如果 w(i,j) > w(j,i)，建立 i → j
如果 w(j,i) > w(i,j)，建立 j → i
如果两者相等，则暂不建立方向
```

边的权重可以定义为：

```text
margin(i,j) = abs(w(i,j) - w(j,i))
```

权重越大，说明顺序越稳定。

### 7.2 检测环

多数关系图仍可能存在环，例如：

```text
A → B
B → C
C → A
```

可以使用 Tarjan 或 Kosaraju 算法寻找强连通分量。强连通分量中包含多个节点时，说明这些节点之间存在循环顺序冲突。

### 7.3 拓扑排序

如果多数关系图无环，使用 Kahn 算法进行拓扑排序。

当同时有多个入度为 0 的候选节点时，使用以下优先级：

1. 出现频率高的节点优先；
2. 工艺领域预设优先级高的节点优先；
3. 加权出边更强的节点优先；
4. 节点 ID 作为稳定的最终排序依据。

该算法速度快，但不保证得到理论最优的全局路线。

## 8. 正式算法：加权 Kemeny 排序与 CP-SAT

对于每一对节点 `i` 和 `j`，定义二进制变量：

```text
x(i,j) = 1，表示 i 排在 j 前面
x(i,j) = 0，表示 j 排在 i 前面
```

### 8.1 完整性约束

任意两个节点必须有且只有一个先后方向：

```text
x(i,j) + x(j,i) = 1
```

### 8.2 传递性约束

为了保证全局顺序不产生环，需要满足：

```text
如果 i < j 且 j < k，则 i < k
```

一种线性约束写法是：

```text
x(i,j) + x(j,k) - x(i,k) ≤ 1
```

也可以使用等价的三角不等式约束。

### 8.3 硬约束

如果工艺规则要求 `i` 必须在 `j` 前面，则加入：

```text
x(i,j) = 1
```

如果硬约束本身形成环，模型应直接报告工程规则冲突，而不是强行生成路线。

### 8.4 目标函数

目标是最大化满足的样本顺序权重：

```text
Maximize Σ w(i,j) × x(i,j)
```

对于同一对节点，也可以使用差值形式：

```text
Maximize Σ [w(i,j) - w(j,i)] × x(i,j)
```

它等价于最小化样本顺序的加权违反次数。

该问题在排序理论中对应加权 Kemeny 排序，在图论中对应加权最小反馈弧集问题。

## 9. 使用位置变量的 CP-SAT 表达

实际使用 OR-Tools CP-SAT 时，也可以为每个节点定义位置变量：

```text
pos[i] ∈ [0, N-1]
```

并要求：

```text
AllDifferent(pos[i])
```

表示每个节点占据唯一位置。

硬约束：

```text
pos[i] < pos[j]
```

样本偏好通过布尔变量表示：

```text
b(i,j) = 1，当 pos[i] < pos[j]
```

目标函数最大化：

```text
Σ w(i,j) × b(i,j)
```

对于每个样本中的节点对 `(i,j)`，如果最终顺序违反 `i → j`，就产生对应的惩罚。

| C / C1 | C→C1：4，C1→C：1 | C→C1 |
| D / D1 | 各 2 次 | D→D1 |
| E / E1 | E→E1：1，E1→E：2 | E1→E |
| F / F1 | F→F1：3，F1→F：1 | F→F1 |
| G / G1 | G→G1：4，G1→G：1 | G→G1 |
| H / H1 | H→H1：2，H1→H：1 | H→H1 |
| J / J1 | J→J1：1，J1→J：2 | J1→J |
| K / K1 | 各 2 次 | K1→K |

这条路线不能同时满足以下局部顺序：

```text
E → E1
J → J1
K → K1
D1 → D
H1 → H
F1 → F
B1 → B
C1 → C
G1 → G
```

这些冲突不是算法错误，而是样本之间本身存在相反顺序。算法做的是在所有冲突中选择总体代价最小的方向。

## 11. 结果评价指标

不能只看最终路线，还应同时输出以下指标。

### 11.1 相邻顺序一致率

检查每条样本中相邻节点在最终路线中的顺序是否保持：

```text
相邻一致率 = 未违反的样本相邻关系数 / 样本相邻关系总数
```

该指标适合评价工艺路线的局部连续性。

### 11.2 全对顺序一致率

检查每条样本内所有节点对的相对顺序：

```text
全对一致率 = 满足的节点对数 / 节点对总数
```

该指标更接近 Kemeny 排序的优化目标。

### 11.3 加权违反代价

对于被违反的关系，根据其支持次数进行加权：

```text
违反代价 = Σ 被违反关系的支持次数
```

优先避免违反高频、强共识的工艺关系。

### 11.4 冲突解释

每一个被违反的关系应记录：

- 节点对；
- 支持正向的样本数量；
- 支持反向的样本数量；
- 被违反的样本编号；
- 最终选择该方向的原因。

## 12. 复杂度和规模建议

设全集节点数为 `N`，样本数量为 `m`，平均样本长度为 `L`。

关系统计复杂度约为：

```text
O(m × L²)
```

如果每个样本约 20 个节点，且全集节点数在 20～50 个左右，CP-SAT 或 MILP 通常可以直接求解。

建议规模：

| 全集节点数 | 推荐方法 |
|---:|---|
| 20～40 | CP-SAT 精确求解 |
| 40～80 | CP-SAT，增加硬约束和剪枝 |
| 80～150 | 稀疏模型、局部搜索或分阶段求解 |
| 150 以上 | 启发式排序、分层拓扑排序、局部优化 |

注意，复杂度主要取决于全集唯一节点数量 `N`，而不是单个样本长度。

## 14. 与分组模板和 MPS 的关系

该算法输出的是某一典型零件类别的**抽象全集工艺路线**，不是最终的 MPS 加工方法模型。

在完整系统中，流程可以是：

```text
多个典型零件样本
        ↓
生成抽象全集工艺路线
        ↓
建立分组模板与工序/工步的关系
        ↓
MPS识别具体零件的分组特征
        ↓
根据分组特征从全集路线中筛选工步
        ↓
生成具体零件的抽象工艺路线
        ↓
返回MPS继续完成加工方法和工序模型生成
```

因此，本算法在整个系统中承担的是：

> **将多个样本路线整理成一套有序、可解释、可追溯的典型零件抽象全集路线，为后续分组模板驱动的具体零件路线实例化提供基础。**

## 15. 最终推荐

正式系统建议采用以下组合：

```text
标准化节点ID
    + 全对关系权重统计
    + 工艺硬约束
    + Tarjan冲突检测
    + CP-SAT加权Kemeny优化
    + 路线来源和冲突证据输出
```

其中：

- Kahn 拓扑排序用于快速预览和初始解；
- CP-SAT 用于正式求解冲突最少的全集工艺路线；
- Tarjan 用于定位循环冲突；
- 工程师确认结果可以沉淀为新的硬约束或高权重规则。
