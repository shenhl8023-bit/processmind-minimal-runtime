# Win7 fix7 更新说明与验收记录

日期：2026-10-28。状态：候选包，等待 Windows 7 SP1 x64 实机验收。

## 本次已定位并修复的缺陷

1. 关闭失败时，旧逻辑仍删除 PID 状态并返回成功，导致下一次关闭找不到原服务。现在关闭失败返回 1、显示错误并保留状态；即使 taskkill 返回成功，也要确认原 PID 已退出。
2. 原进程查询依赖 WMIC，查询没有超时，重定向输出还有系统编码差异。现在优先使用离线运行时随附的 psutil 读取 Unicode 命令行，WMIC 和 netstat 只作有超时的后备查询。进程存在性另有 Windows 原生 API 后备路径。
3. 状态文件丢失时，以前可能误报“未运行”。现在依据实际端口监听 PID 和当前安装目录恢复状态；无法确认归属时明确报错，保留无关进程。
4. 健康接口及监听 PID 本身不能证明进程属于当前目录。现在必须读取匹配当前安装目录的进程命令行才能复用或关闭进程；命令行不可读时明确失败并保留状态，避免误关 PID 复用后的其他实例。也拒绝从其他安装目录覆盖仍有效的运行状态。
5. 已记录 PID 确实退出，而同一目录服务在原端口重启时，状态和关闭命令可重新识别监听进程并恢复状态。
6. 启动失败且子进程未能关闭时保留状态；同一运行目录已有服务时，不能换端口覆盖它的状态。
7. 状态命令现在仅在服务属于当前安装目录且健康时返回 0，其余情况返回 1；关闭命令默认读取记录的端口。
8. 三个命令窗口保留执行结果，按任意键只关闭该命令窗口。脚本使用 ASCII、CRLF，正确传递错误码，支持自动化设置 PROCESSMIND_NO_PAUSE=1。
9. 在 Python 3.8 和锁定的 PyMuPDF 中复现工序号“1 0”被读成“1”的问题，已修复同一行工序号数字间空格的识别。
10. 状态文件端口损坏时，查询只报告错误并保留记录，不再删除仍可能对应活进程的状态；后续关闭也返回失败，避免误报已退出。
11. 新进程启动后写状态失败时，尝试停止本次启动的进程；若仍无法确认退出，显示 PID、自定义端口恢复命令和日志路径，返回失败。
12. 同一运行目录的启动、关闭和状态查询使用跨进程文件锁。另一个命令执行中时明确提示稍后重试，避免同时双击启动覆盖或删除成功实例的状态；进程退出自动释放锁。锁文件保留是正常行为，不要手动删除正在使用的锁文件。

规则编辑仍适用于当前任务中的任意工序、字段和关联关系，镀铜、除铜只是示例。没有把这些示例设为系统固定业务逻辑。

## 使用方式

1. 先从旧安装目录执行 stop-win7.cmd，确认成功。把候选 ZIP 解压到新的空目录。保留用户现有数据，无需删除数据库或运行目录。
2. 双击 start-win7.bat 启动；服务在后台运行，默认页面为 http://127.0.0.1:8000/。
3. 双击 status-win7.cmd 检查状态。running=true 且 owned=true 表示当前目录服务健康。
4. 双击同一目录的 stop-win7.cmd 退出；必须确认“已停止”或“当前未运行”。失败时保留错误窗口，查看日志后重试，不要执行 taskkill /IM python.exe。
5. 默认数据、日志和状态位于 %LOCALAPPDATA%\ProcessMind。日志文件是 logs\api.err.log、logs\api.out.log。更换目录前，应先从旧目录停止旧进程。

自动化调用（在包目录的 cmd.exe 中执行）：

~~~bat
set "PROCESSMIND_NO_PAUSE=1"
call start-win7.bat --no-browser
echo %ERRORLEVEL%
call status-win7.cmd
echo %ERRORLEVEL%
call stop-win7.cmd
echo %ERRORLEVEL%
~~~

状态：健康返回 0，未运行或无法确认返回 1。关闭：成功停止或确认已经退出返回 0；无法确认归属或关闭失败返回 1。自定义端口可用 start-win7.bat --port 18087；状态和关闭默认读取记录的端口，状态文件丢失时需要显式传入同一 --port。

.runtime\python\python.exe scripts\verify-win7-package.py .
call start-win7.bat --port 18087 --no-browser
echo %ERRORLEVEL%
call status-win7.cmd --port 18087

echo %ERRORLEVEL%
call status-win7.cmd --port 18087
echo %ERRORLEVEL%
