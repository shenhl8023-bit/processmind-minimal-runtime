# 工艺知识库界面审查

日期：2026-10-26。范围：本地运行的 /knowledge，知识问答、工艺知识、工艺资源及记录详情；结合实际截图、浏览器布局与计算样式，以及现有 Vue/CSS。使用 frontend-design、ui-ux-pro-max 和 Superpowers 的审查指导。本文件是审查建议，不是已实施的改版。

## 判断

问题集中在同一页面的视觉尺度与信息密度不一致：顶栏是胶囊按钮，侧栏是紧凑导航，问答区是宽松卡片，资料区则是小字号数据表。外层标题、内层标题、资料标记与说明叠加，抢占了表格阅读空间。建议维持现有品牌强调色与三个入口，以清晰、克制的工业资料工作台为方向，优先统一局部规范。

## 方案比较与推荐

1. 只调整颜色与圆角：成本低，但难以解决首屏层级过多与表格阅读问题。
2. 保留布局的局部统一（推荐）：保留三入口、主色、问答、只读表格与详情，统一字级/间距/控件，压缩头部，整理示例网格与详情层级；影响集中在知识库。
3. 全站重新设计：能重整全局工作流外壳，但范围大，暂时没有必要。

推荐分两批：第一批处理字体对比、间距圆角、示例网格与紧凑头部；第二批处理表格定位/分页、详情结构与窄屏适配。不要添加装饰性指标卡、大面积渐变、无业务意义动画或新的在线字体依赖。

## 兼容与验收约束

- 保持 Win7 SP1 x64、CPython3.8.10、Chrome/Edge109 的既有交付约束。审查在macOS浏览器进行，不等同于Win7实机验收。
- 本地中文字体回退应覆盖 Microsoft YaHei、Segoe UI 等已有字体；不为视觉统一增加安装依赖。
- 后续使用现有Vue与CSS能力，避免依赖较新浏览器特性；不修改Win7依赖锁、启动器或打包脚本。
- 保留返回第一步、三入口的查询状态、每页20项、来源、核对状态、异常与原始字段。
- 重新核验问答/工艺知识/工艺资源/详情的常态、空结果、加载和异常状态；确保键盘焦点可见、长文本可查且主页面不产生横向溢出。
