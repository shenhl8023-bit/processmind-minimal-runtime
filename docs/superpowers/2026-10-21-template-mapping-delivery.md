# 模板映射独立步骤交付记录

## 已实现

- 流程为：上传资料 → 路线归并 → 规则分析 → 模板映射 → 规则定稿 → 验证生成。
- 模板映射使用独立页面，沿用现有导航、配色、卡片、三栏编辑与底部操作样式；第二步旧弹窗保留兼容。
- 按第三步最终路线的名称和顺序展示，使用来源工序 ID、原始工步位置保存映射。
- 至少一条有效且已确认的映射即可继续和发布；不要求全部工序映射。模型候选必须经用户确认。
- 前后端均校验来源、工步位置、模板路径和特征有效性。
- 修复发布时用简化工步名称校验导致误判的问题，以及显式清空草稿后恢复旧映射的问题。
- 读取已保存工序树不再重复触发模型排序。旧后端进程已重启加载当前代码，同一接口实测由约 25 秒降为 0.030 秒；该数值仅代表本地此次读取请求。
