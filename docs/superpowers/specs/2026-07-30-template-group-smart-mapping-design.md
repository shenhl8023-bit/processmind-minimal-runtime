# 模板分组智能映射设计

## 目标

将当前“关键词命中失败后放入当前分组”的行为，改为“确定性候选约束 + 大模型受控选择 + 用户审核疑难项”。系统优先减少错误映射，而不是追求全部自动映射。

## 核心原则

- 当前选中的模板分组只用于手工映射，不参与智能映射兜底。
- 模板分组使用现有 ID；程序和模型均不得创建新分组。
- 规则能唯一确定位置和特征时，生成高置信度建议。
- 只能确定特征、不能确定 A侧/B侧/周边时，保留多个候选供用户选择。
- 大模型仅从程序提供的候选 ID 中选择，并返回置信度、证据和说明。
- 模型不可用、返回非法 ID 或置信度不足时，保留规则候选，不强行映射。
- 已有人工映射不被智能映射覆盖；重新分析只处理未映射项。

## 数据流

1. 前端从工序名称、工步和模板树提取加工特征与位置。
2. 确定性引擎生成候选分组、规则置信度和解释。
3. 唯一且证据完整的候选可直接加入草稿。
4. 多候选项批量发送后端，后端调用当前配置的大模型。
5. 后端校验模型只能返回请求中的工序 ID 和候选分组 ID。
6. 高置信度模型结果加入草稿；其他结果在工序行中显示候选按钮。
7. 用户点击候选完成映射，最后使用现有“保存映射”持久化。

## 置信度

- `high`：位置和加工特征都有明确文本证据，且候选唯一。
- `medium`：模型在合法候选中选择，但仍需要用户核对。
- `low`：位置缺失、语义冲突或模型未给出可靠选择，保持未映射。

## 界面

- “智能映射”运行时显示加载状态并禁用重复点击。
- 运行后显示自动映射数、待确认数和未识别数。
- 待确认工序显示原因、置信度及最多三个候选分组按钮。
- 不再把未识别工序放入当前选择的模板分组。

## 测试

- “打孔”必须给出 A侧/孔、B侧/孔、周边/孔候选，不得落入当前外圆分组。
- “磨外圆”在没有侧别时只能给出 A侧/外圆、B侧/外圆候选。
- 明确“A侧端面”时生成唯一高置信度 A侧/端面建议。
- 非法模型分组 ID、低置信度和模型不可用均保持规则候选。
- 已有映射不会被重新分析覆盖。
