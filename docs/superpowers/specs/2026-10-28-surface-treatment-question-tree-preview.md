# 统一入口与方案比较

本预览采用“先选原因，再问细节”的建议方案。材料排在第一项，但系统不预选材料，也不把所有工序强制放进材料分支。以下是供审阅的话术与分支，尚未写入系统配置。

| 方案 | 问法与取舍 |
| --- | --- |
| A 原因入口 本文采用 | 先展示原因方向，再按选择追问；多一步选择，能覆盖材料、要求与工序依赖。 |
| B 固定先问材料 | 所有工序先选牌号或类别；材料驱动时较快，依赖前后工序时容易答偏。 |
| C 保留目标入口并增加切换 | 改动较小，但仍先假定由工艺要求驱动；可作临时兼容方案。 |

## 共同的第一问

这道【工序名】是否出现，主要由以下哪类条件决定？

~~~tree
第一问
├─ A 与材料相关 → 牌号或类别 → 具体材料范围
├─ B 与工艺或质量要求相关 → 要求类型 → 具体要求
├─ C 与前后工序相关 → 关联工序 → 触发与排序
├─ D 与处理部位或表面状态相关 → 对象 → 具体状态
├─ E 多种因素共同决定 → 分别问清 → 组合逻辑
├─ F 其他原因 → 自由补充 → 转成可判断条件
└─ G 暂不确定 → 标出缺项 → 保存待补充
~~~

## 共同的进入与结束规则

全覆盖工序沿用现有不自动发问的入口规则；样本全覆盖不等于已经证明该工序对所有材料或任务都无条件适用。组合名先确认统一名称，仍非全覆盖时再进入原因选择。

只沿选中的方向继续，已明确的信息可带入下一题确认。选择“防护”“屏蔽”“材料相关”等宽泛方向后，应继续问到可判断条件，再生成待确认草稿。树答完不等于规则已确认或已发布。

材料候选、关联工序和技术要求优先来自当前项目文档及提取字段，并允许人工补充。以下问法用于审阅提问结构，不代表已确定某种材料必须进行某项处理。

条件示意：当【指定的镀铜工序出现】，且【该铜层在后续阶段需要去除】时，安排除铜；另行记录相对位置。

# 各分支如何收敛为规则

## 材料分支需要区分范围与触发

~~~tree
选择材料相关
├─ 按牌号／按类别 → 勾选具体范围，可人工补充
├─ 多个材料选项 → 默认解释为任一材料，供用户确认
├─ 问：满足材料条件，就一定需要该工序吗？
│  ├─ 是 → 形成材料条件，检查有无排除项
│  └─ 否 → 补充其他条件，明确二者怎样组合
└─ 材料只是适用范围 → 单独保留，不推成充分条件
~~~

## 工序依赖需要同时问清出现与位置

~~~tree
选择前后工序相关
├─ 从当前项目选择工序，重复名称需定位具体一次
├─ 问：对方出现是否触发本工序？
│  ├─ 是 → 记录触发依赖，继续确认附加条件
│  └─ 否 → 只记录排序，继续补问出现条件
├─ 对方不存在也可能触发 → 明确不存在的判断范围
└─ 确认排在何道工序前后，检查循环依赖
~~~

## 联合条件与其他原因的追问

联合条件先逐项问清材料、要求、部位、状态或关联工序，再明确“全部满足”“任一满足”和排除项。允许三个及以上因素，并保留分组，不只问“谁是主因素”。自由补充同样要明确字段、对象、取值与判断方式；无法结构化时保留原话并标出缺项。

## 统一结束检查

1. 已有可判断的具体条件；数值条件含单位、比较方式和阈值来源。
2. 已区分材料适用范围、出现条件和工序排序。
3. 能说明何时出现、何时不出现；否定与例外已记录。
4. 样本支持与反例可核对；资料缺失不等于条件为否。
5. 用户确认草稿后，才沿现有流程进入后续规则确认。

已获得足够具体的条件时可跳过重复提问；如果仍只有“防护”“材料相关”等方向词，应继续补充。存在不确定、资料缺失、对象不明或条件无法区分的情况，保存待补充。

# 审阅要点与实现边界

以下案例用于检查问题树是否覆盖真实业务，不是对实际零件的工艺结论。所有示意材料集合、要求和数值均由项目数据或用户提供。

| 审阅场景 | 预期问答结果 |
| --- | --- |
| 同一种材料，有的样本镀铜、有的不镀铜 | 材料不足以解释出现条件，继续补充具体要求或工序依赖。 |
| 不同材料均出现相同表面处理 | 允许工艺要求直接作为触发，不强制选择材料。 |
| 除铜依赖某次镀铜且还需清除辅助层 | 两个条件分别记录并确认同时成立，另记排序。 |
| 来料已有铜层，当前路线没有镀铜 | 按来料表面状态及去除要求判断，不强造前序。 |
| 仅要求排在某道工序后面 | 记录排序，继续补问何时安排本工序。 |
| 只选防护或屏蔽 | 继续询问具体对象和要求，不直接结束。 |
| 只知道需要处理，方法尚未确定 | 保留已有统称和缺项，不自动指定具名工序。 |
| 资料缺失或用户暂不确定 | 保存待补充，不生成已确认规则。 |

## 落地时需要同步的部分

共享模板与本地工序模板要同步调整入口；钝化匹配要消除与热处理模板的重叠。原因选择、材料追问和草稿区可复用现有能力；前后工序的显式入口、部位与状态的具体分支、联合条件衔接及充分性检查需要补充并验证。

仅把材料选项排到前面不足以完成调整。当前直接进入要求分支的设置会跳过原因选择；当前要求分支也设置了选类型后跳过范围追问。历史已确认规则不自动改写，重新问答与原草稿的衔接需要保持可追溯。
