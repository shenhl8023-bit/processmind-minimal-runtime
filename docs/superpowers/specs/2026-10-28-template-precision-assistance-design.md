# 模板映射精度补全与保存校验

目标：在模板映射中由大模型辅助补全加工阶段（粗加工、半精加工、精加工），保存前定位漏填工序。

采用现有模型配置提供只读建议：根据完整路线、工序工步和来源证据，仅填补尚未填写的加工工序。保留已有值及请求期间人工修改；证据不足、低置信度、非法输出或模型不可用时保持待确认并说明原因。辅助工序固定为辅助工序，不询问用户加工精度。建议以标记与理由展示，用户可修改，点击保存即确认。

界面提供“智能判定精度”，全局“智能推荐”同时补全缺失精度。保存前列出具体漏填工序、标红字段、滚动并聚焦首项，阻止提交与进入规则定稿；服务端对显式最终路线同步拒绝缺失/非法精度，不修改映射版本或现有规则包。旧版来源工序接口兼容保留。

方案比较：完全自动覆盖可能破坏已确认值；纯手填增加重复劳动；采用仅补空值的模型辅助加前后端必填校验。该选择依据用户本轮提出的自动判断和保存提醒需求。

范围：不重新划分既有路线、不修改当前业务映射、不修改三表字段。
