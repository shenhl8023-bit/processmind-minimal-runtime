# 模板分组工步映射与叶子特征校验设计

## 目标

建立本系统内部通用的模板映射模型：用户导入 XML 分组模板后，系统将标准路线中的工序和工步与模板分组及特征选择建立可审核、可追踪的关系。

当前设计不依赖任何外部系统的代码、文件格式或运行时实现。外部系统适配属于后续独立工作，本阶段只维护本系统的中间语义模型和映射审核流程。

## 核心语义

### 工序与工步

- 工序是路线层级的容器，保留名称、顺序、类型、技术要求和工步顺序。
- 工步是模板匹配的最小单元，例如“平端面、车外圆、钻孔、车槽”。
- 一个工序可以包含多个工步。
- 一个模板分组可以关联多个工序中的多个工步。
- 一个工步可以关联一个或多个模板叶子分组及其特征选择。
- 工序级映射只作为汇总和展示，不替代工步级正式映射。

### 父分组与叶子分组

- 父分组用于表达区域、方向、零件部位和组合范围，例如“A侧”“B侧”“壳体/内腔”。
- 叶子分组用于表达可落地的特征，例如“端面、外圆、孔、槽”。
- 父分组可以没有自身特征，但其后代必须继续展开到合法叶子。
- 叶子分组必须至少配置一个合法特征。
- 父分组可以被用户选中作为批量匹配范围，但最终保存的工步映射应落到后代叶子分组。
- 界面可以汇总显示“车削 A 侧 → A侧”，但该关系由 A 侧下的工步映射计算得出，不单独创建一条模糊的父分组目标映射。

示例：

```text
车削加工（A侧）
  平端面 → A侧 / 端面 → 轴端面
  车外圆 → A侧 / 外圆 → 外圆柱面
  钻孔   → A侧 / 孔   → 孔(盲孔)、孔(通孔)
```

## 模板标准校验

- 有子节点的父分组可以不配置“特征选择”。
- 没有子节点的叶子分组必须至少配置一个非空特征。
- 每个非空特征必须存在于系统内置 `FeatureTemplate.xml`。
- 空特征叶子产生阻断问题：

```text
code: missing_leaf_feature_selection
message: 叶子分组必须至少配置一个特征选择。
path: 当前叶子分组的完整路径
value: 空字符串
```

- 存在空特征叶子、非法特征或其他阻断问题时，`can_confirm=false`。
- 新模板确认、更换和重新上传时执行校验。
- 已确认的历史模板不后台批量重校验、不自动删除，只有用户主动操作时才应用新规则。

真实样例预期：

- `临时壳体4.xml`：通过，9 个叶子分组均有合法特征。
- `套筒类.xml` 和 `套筒类(未指定参数).xml`：通过，空特征节点均为父分组，15 个叶子分组均有合法特征。
- `新衬套模板.xml`：不通过，存在空特征叶子。
- `飞机壁板类1.xml`：不通过，所有叶子分组均缺少特征。

## 内部映射模型

当前工步来自路线数据中的工序 `step_items`。系统在当前路线修订内生成确定性工步键：

```text
source_step_key = <稳定工序键>_s<两位工步顺序>
```

正式映射以工步为单位保存：

```json
{
  "source_operation_id": 41,
  "source_operation_name": "车削加工（A侧）",
  "source_step_key": "turning_a_s05",
  "source_step_order": 5,
  "source_step_name": "平端面",
  "source_step_text_hash": "sha256:...",
  "scope_template_group_path": ["A侧"],
  "template_group_path": ["A侧", "端面"],
  "candidate_features": ["轴端面"],
  "match_mode": "any",
  "status": "confirmed",
  "confidence": 0.96,
  "source": "user_confirmed"
}
```

字段规则：

- `source_step_key` 在当前路线修订内唯一。
- `source_step_text_hash` 用于检测工步文字修改；文字改变后只使受影响工步映射失效。
- `scope_template_group_path` 可为空；有值时用于限制候选只能来自指定父分组后代。
- `template_group_path` 必须指向合法叶子分组。
- `candidate_features` 是该叶子中允许的候选特征集合，同一集合默认按 OR 关系解释。
- `match_mode=any` 是默认模式；本阶段不引入未被现有规则引擎支持的复杂组合表达式。
- 一个工步可以有多条映射记录，导出或规则编译时按工步合并。
- 同一个叶子分组可以关联多个工步和多个工序。
- 正式保存时服务器根据模板路径重新补全稳定分组键和合法特征，不信任浏览器提交的派生字段。
- 不新增工步数据库表；映射继续保存在项目模板的 JSON 数据中。

旧版只有工序 ID 的映射无法准确表达具体工步。系统保留旧数据供追踪，并依据工序下的工步原文进行重新识别；高置信度结果可自动迁移，其他结果进入待审核，不直接删除。

## 映射识别流程

1. 读取当前已确认路线及其工序、工步顺序。
2. 为每个工步生成稳定键、原文哈希和可识别状态。
3. 从模板树提取合法叶子、完整路径和标准特征。
4. 使用受控词典进行工步名称与特征初筛。
5. 使用工序名称中的 A 侧、B 侧、周边等上下文限制父分组范围。
6. 程序只从现有模板叶子中生成候选，不创造新路径、特征或 ID。
7. 唯一且证据充分的候选标记为高置信度建议。
8. 多候选或语义含糊时才调用大模型排序；大模型只能在候选集合内选择。
9. 仍无法判断时保持待处理，由用户逐条确认、删除或补充候选。
10. 父分组批量操作只负责设置范围并触发子工步候选，不直接生成父分组正式映射。

## 前端交互

模板树：

- 父分组显示为“区域/组合”，可展开、收起和作为批量范围。
- 叶子分组显示为“特征”，展示 `feature_selections`。
- 空特征叶子在预览阶段直接显示问题，不进入可映射候选。
- 父分组点击后显示其后代叶子和当前已匹配工步数量。

工序与工步区：

```text
车削加工（A侧）       已匹配 3/3
  平端面              A侧 / 端面 · 轴端面
  车外圆              A侧 / 外圆 · 外圆柱面
  钻孔                A侧 / 孔   · 孔(盲孔)、孔(通孔)
```

- 工序卡片可展开查看工步，不要求用户先处理整道工序。
- 用户可以选择一个工步，再选择一个或多个叶子分组。
- 用户把整道复合工序放到父分组时，系统解释为“在该父分组后代中批量匹配工步”。
- 用户可以移除某个工步的单个候选，不必删除整道工序。
- 高置信度建议默认采用但可展开检查；低置信度、无候选和冲突项必须显式展示。
- 未解决的加工工步阻止正式导出；明确标记为不依赖模板特征的工步可以跳过映射。

## 规则编译边界

本系统内部只编译统一的中间规则模型：

- 工序条件负责决定工序是否出现。
- 工步候选负责决定工序出现后哪些工步与哪些模板特征相关。
- 模板分组路径负责上下文和定位。
- 特征选择负责候选特征集合。
- 主工序、Bool 条件、材料、精度、工序依赖等继续属于第四步规则，不迁入模板映射。

外部系统文件格式、字段命名、脚本适配和兼容测试不属于本阶段。未来由独立适配器读取中间规则模型，适配器不得反向污染本系统映射数据结构。

## 状态失效与兼容性

- 第二步重新推理导致路线变化时，受影响工序和工步映射一起失效。
- 工步顺序、名称或文本哈希变化时，只使对应工步映射失效。
- 更换模板时按完整规范化路径和合法特征迁移映射。
- 路径不存在、叶子特征不合法或范围冲突的旧映射进入待处理列表。
- 失败预览、取消更换和不标准模板不能修改当前正式模板及映射。
- 旧工序级映射保留可追踪快照，迁移完成前不参与新的正式导出。

## 错误处理

- 空特征叶子：阻止模板确认，显示完整路径。
- 不存在的目标路径：拒绝保存，并提示模板已变化。
- 非法候选特征：拒绝保存，不接受浏览器自造值。
- 工步文字已变化：使该工步映射失效，要求重新识别。
- AI 超时或不可用：保留程序候选，低置信度项进入人工审核，不清空其他正式结果。
- 父分组没有可用后代叶子：只能作为展示节点，不能用于批量范围。

## 测试

模板解析测试：

- 空特征父分组且所有叶子合法时通过。
- 空特征叶子产生 `missing_leaf_feature_selection` 并阻止确认。
- 非法非空特征只产生非法特征问题，不重复产生缺失问题。
- 五个真实 XML 样例符合既定结果。

映射服务测试：

- 一个工序的多个工步分别匹配不同叶子分组。
- 一个分组可以关联多道工序中的多个工步。
- 一个工步可以保存多个候选叶子和多个候选特征。
- 父分组批量范围只生成后代叶子映射，不生成父分组目标记录。
- A 侧工序不会自动匹配 B 侧分组。
- 工步文字修改后只有该工步映射失效。
- 大模型不能返回候选集合之外的分组或特征。
- 旧工序级映射只在高置信度时自动迁移。

前端测试：

- 工序可以展开查看全部工步及其映射状态。
- 父分组可展开和作为批量范围，叶子分组可作为正式目标。
- 用户可以为一个工步增删多个候选叶子。
- 高置信度结果默认采用，待处理项阻止导出。
- 模板更换、取消和旧映射迁移状态展示准确。

## 非目标

- 本阶段不修改任何外部系统代码或兼容文件。
- 本阶段不新增外部系统专用字段。
- 本阶段不把第四步工序条件合并到模板映射。
- 本阶段不新增工步独立数据库表。
