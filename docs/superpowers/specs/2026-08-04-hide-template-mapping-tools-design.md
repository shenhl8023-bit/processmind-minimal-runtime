# 临时屏蔽分组模板映射入口

## 目标

在路线归并结果页隐藏“分组模板映射”和“详细信息”两个操作入口，暂时阻止用户打开映射弹窗或展示模板别名明细。

## 实现范围

- 在 `ExtractRouteShellHeader.vue` 中增加一个命名明确、默认关闭的本地功能开关。
- 仅在开关开启时渲染“分组模板映射”和“详细信息”两个按钮。
- 保留现有弹窗、事件接口、映射状态、持久化和路线数据序列化逻辑，避免改变已有数据及 KmAI 兼容导出行为。
- 保留工作区中已有的“模板分组映射”改名为“分组模板映射”的文案修改。

## 用户可见行为

- 路线归并结果页不再显示上述两个按钮，右侧的“重新推理”入口保持原位置和行为。
- 已保存的模板映射不会被删除或清空。
- 模板别名明细保持关闭，页面没有其他入口可以重新开启。

## 测试

新增 `ExtractRouteShellHeader` 的 SSR 渲染测试。测试在原有按钮本可启用的属性组合下渲染组件，并断言输出不包含“分组模板映射”和“详细信息”，同时确认“重新推理”仍然存在。

实施时先运行新增测试并确认它因两个入口仍然存在而失败，再加入功能开关并确认测试、前端构建通过。

## 恢复方式

后续需要重新开放功能时，只需开启或移除该本地功能开关，无需恢复底层映射和导出逻辑。
