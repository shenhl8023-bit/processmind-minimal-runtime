# 生成页“是/否”字段集中展示设计

## 目标

在工艺路线生成页的输入面板中，将全部布尔型（`boolean` / `bool`）字段从普通字段流中分离出来，集中放入一个紧凑、美观的“工艺选项”分组，减少用户在长表单中的上下滚动与查找成本。

## 范围

- 仅调整前端 `GenerateInputPanel` 的字段展示顺序与样式。
- 所有当前与未来来自规则包的布尔字段均自动归入“工艺选项”分组。
- 文本、数值、单选、多选等非布尔字段继续按现有顺序展示。
- 不改动规则包、后端接口、字段默认值、表单校验、填写进度、清空、示例填充或生成请求。

## 布局与交互

1. 普通输入字段按当前顺序展示。
2. 若存在布尔字段，在普通字段之后、底部操作区之前渲染一个“工艺选项”卡片，并显示该分组的字段数量。
3. 卡片内每个选项由字段名称与“是 / 否”切换组成；继续复用现有选中态、键盘可操作按钮和 `setFieldBoolean` 回调。
4. 桌面端采用两列网格，保持卡片高度紧凑；在窄屏下自动退化为单列，避免文字或按钮挤压。
5. 已有值的完成标识与非布尔字段一致，以便进度统计和视觉反馈保持统一。

## 实现边界

- 在组件内以 `isBooleanField` 派生 `standardFields` 与 `booleanFields`，不改变传入 `inputFields` 的数据。
- 复用现有选择按钮、字段来源元数据和字段类型标签，避免产生两套状态逻辑。
- 当规则包没有布尔字段时，不渲染空分组。

## 错误处理与兼容性

- 布尔字段仍以 `true` / `false` 写入原有 `fieldValues`，未选择时保持原有 `undefined` 语义。
- 若规则包新增任意 `boolean` 或 `bool` 类型字段，将自动出现在该分组，无需额外配置。
- 所有非布尔字段、字段顺序和必填规则保持不变。

## 验证标准

- 含多个布尔字段的规则包中，页面只出现一个“工艺选项”分组，所有布尔字段均位于其中。
- 选择“是”或“否”后，完成计数、字段值和生成请求与调整前一致。
- 没有布尔字段时，不出现分组卡片。
- 窄屏样式下分组切换为单列且无内容溢出。
