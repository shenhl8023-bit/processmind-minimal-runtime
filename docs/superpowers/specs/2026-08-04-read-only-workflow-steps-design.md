# 顶部流程步骤条只读设计

## 目标

顶部五步流程条仅展示当前进度，禁止用户通过鼠标或键盘点击步骤项跳转页面。各页面底部已有的“返回”和“进入下一步”按钮继续承担流程导航。

## 变更范围

- 修改 `process-plan-agent-ui/src/App.vue` 中的顶部步骤条。
- 保留五个步骤、当前步骤、已完成步骤、可用步骤及锁定步骤的颜色、圆点和连线状态。
- 移除步骤项的点击与 Enter 键事件、`button` 角色、`tabindex`、跳转提示和可点击光标。
- 删除只为步骤跳转服务的 `useRouter`、路由实例和跳转函数。
- 不修改页面底部导航按钮、Vue Router 路由表、项目上下文或流程状态判断。

## 交互与可访问性

步骤条作为只读进度信息展示。当前步骤继续通过 `aria-current="step"` 标识；非当前步骤不再暴露为按钮，也不进入键盘焦点顺序。鼠标悬停不再显示可点击反馈。

## 测试

先添加一个针对 `App.vue` 的回归测试并确认失败，验证步骤条不存在点击、键盘和按钮语义，同时仍保留进度状态相关绑定。完成最小实现后运行该测试、前端完整测试及生产构建。

## 完成标准

1. 点击顶部任意步骤的圆点、文字或容器均不会改变路由。
2. 使用键盘无法聚焦或触发顶部步骤项跳转。
3. 步骤条的当前、已完成、可用和锁定视觉状态保持不变。
4. 页面底部前进、后退按钮行为不受影响。
