# 条件必填导出与接收端兼容修复

用户确认：保持现有特征选择方式、校验要求和三个JSON文件；补齐导出与接收端，用户无需重设规则。

现有故障：共享参数在选择特征后才必填，样包适配器拒绝导出；导出错误复用了生成失败提示。

方案选择：取消动态校验会漏拦缺项；将全部参数固定必填会要求用户填写未选择特征。采用因素表可选required_when，保持按特征选择的必填语义。它复用三表普通因素条件，不引用selected_processes、some或数组来源。没有此字段的旧包不变。

实现决定：共享参数输出required_when={field:同特征present,op:eq,value:true}，替代该参数静态required；导出短编号同步转换条件引用。TS及Python三表验证器检查新条件，接收端完成全部因素取值后执行；预览模式允许缺项。读取器交付文件放在integrations/kmai，并同步本机现有读取器。

验收：导出恰为三个数组；未选/缺方位/缺IT/缺Ra/完整输入与原生行为一致；跨特征独立、短编号引用、因素顺序、旧包及预览回归；生产构建、Python3.8静态兼容及浏览器真实下载。保留正式数据，不声称已完成另一电脑安装或Win7实机验证。
