# 模板映射到三文件导出的深度测试计划

> **For agentic workers:** Follow Superpowers systematic-debugging, test-driven-development, requesting-code-review and verification-before-completion.

**Goal:** 通过真实浏览器、隔离数据与下游引擎差分测试，找出并修复映射之后的规则发布缺陷。

**Architecture:** 主线负责隔离浏览器全流程与最终 ZIP 文件检查；独立审查分别覆盖映射状态、三表语义和前端编译。每个真实缺陷先构造失败用例，再做最小修复，最后合并验证。

**Tech Stack:** Vue/TypeScript/Vitest、FastAPI/Pytest/SQLite、Tabbit/Playwright、实际 ConfigRouteEngine。

**Spec:** 用户 2026-10-28 要求深入测试模板分组映射后导出规则包、提示验证及最终三个文件格式，发现缺陷及时修复。

## 约束

- 保留当前大量未提交变更，不回滚、不批量提交。
- 真实项目只读；需要保存、改规则、发布、重生成的浏览器场景使用隔离数据副本。
- 不根据已有测试数量判定质量；每项发现需有可执行复现与实际影响。
- 三表必须使用同一快照，使用真实下游引擎读取和执行；不能仅断言服务端自校验通过。
- Python 3.8 与现有 Win7 交付约束继续保持。
