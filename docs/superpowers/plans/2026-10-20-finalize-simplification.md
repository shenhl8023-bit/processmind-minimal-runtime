# 第四步规则定稿操作简化

目标：保留左右布局和系统既有视觉风格，减少操作入口，明确用户确认与发布边界。

- [ ] 更新发布测试：所有未确认条件/关联规则阻止发布，编译、保存和下载均不得执行。
- [ ] 实现统一待处理集合及按路线顺序定位下一项；摘要直接显示当前结构化条件。
- [ ] 卡片保留确认规则、修改、更多；更多收纳始终保留该工序、改为人工选择、恢复默认；依据折叠。
- [ ] 默认仅看待处理，勾选后显式批量确认；发布不自动确认；失败留在待处理并可重试。
- [ ] 运行前端测试、构建及浏览器检查，保留用户第四步页面。

约束：不增加依赖，不改变主导航与页面布局，不修改用户现有规则数据用于测试，不提交混合工作区。
重点验证：高置信度未确认候选、来源已变化、批量部分失败、人工选择转换、长条件及窄视口。
