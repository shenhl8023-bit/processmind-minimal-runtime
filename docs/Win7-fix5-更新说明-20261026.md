# Win7 fix5 更新说明

完整包：`processmind-win7-windows-20261026-fix5.zip`。

fix4 打包时误用了 Python 3.13，导致 Win7 在加载解释器时提示缺少 `api-ms-win-core-path-l1-1-0.dll`。fix5 整套恢复 Python 3.8.10 x64 及对应的第三方依赖，保留 fix4 的分组映射、模型响应解析、合并拆分和停止器修复。

## 使用步骤

1. 关闭 fix4 弹窗及启动窗口。如果先前已有正常运行的 ProcessMind 服务，先在对应旧包目录运行 `stop-win7.cmd`。
2. 将 fix5 完整解压到一个新的空目录，不要覆盖到 fix4 文件夹，避免残留不兼容的 Python 3.13 文件。
3. 已安装 KB2533623 的机器无需因本次错误重新安装更新。
4. 双击新目录中的 `start-win7.bat`，浏览器基线为 Chrome 109 或 Edge 109。
5. 测试打开系统、执行分组映射，并运行 `stop-win7.cmd` 后再次启动，确认停止后 8000 端口已释放。

原有数据默认位于 `%LOCALAPPDATA%\ProcessMind`，无需删除该目录。若使用了自定义数据路径，沿用原来的路径设置。

## 验证范围

核心五文件已与官方 CPython 3.8.10 x64 校验；完整运行时与此前成功运行的 Win7 包逐文件比较。后端 651 项、前端 306 项自动化测试通过，9 项 Windows/PowerShell 测试在开发机跳过。包内校验器新增运行时版本、依赖版本、兼容 DLL 和已知原生依赖检查。

构建机为 macOS，本轮尚未在 Win7 虚拟机执行 fix5；请按功能测试方案复测启动和实际业务。文件校验通过不等于 Win7 业务验收通过。
